# Social Reply Bot

AI-powered Reddit & X/Twitter auto-reply bot for product growth.

**Full repository:** https://github.com/mguozhen/social-bot

## What it does

- Searches Reddit subreddits and X/Twitter for posts matching your product keywords
- Claude AI generates genuine, on-topic replies (not spam)
- Browser automation — no Reddit/X API key needed
- Reddit karma warmup mode for new accounts
- Lead tracking with 1-10 scoring
- Flask web dashboard for monitoring

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/mguozhen/social-bot/main/install.sh | bash
```

## Requirements

- Python 3.9+
- `browse` CLI
- `ANTHROPIC_API_KEY`
